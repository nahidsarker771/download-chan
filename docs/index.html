What's inside

Everything between “I want that file” and “it's on my phone”.

No browser tabs, no sketchy download sites, no 47-step wizard. Just a clean queue.

Clipboard auto-download

Copy a link, switch to the app, and it starts. A 24-hour duplicate guard stops accidental repeats, and you can switch it off in Settings.

Multi-thread engine

Up to 16 parallel connections for direct links, ADM-style. If the server doesn't support ranges, it quietly falls back to a single connection.

Video → MP3

Save video as MP4, or pull the audio out as MP3 when you only want the sound.

Social video support

YouTube, Instagram, Facebook, TikTok, Douyin, X/Twitter, Vimeo and Reddit via a bundled yt-dlp extractor — no external server involved.

Cookies import

Import a cookies.txt from your browser for private or login-walled posts that need it.

Share sheet + clean files tab

Send a link from any app straight to Download Chan. Expand details, cancel, retry, open, share or delete from one place.

About the project

A download manager that stays out of the way.

Download Chan is a small Capacitor app with a native Java download engine. The heavy lifting — yt-dlp and ffmpeg — is bundled inside the APK, so nothing is proxied through someone else's server.

Files land in Downloads / Download Chan when Android's “All files access” permission is granted. If you'd rather not grant it, the app falls back to its private folder and tells you exactly where the file went.

“A download button should download the thing. That's the whole product.”

It is a sideload build: debug-signed, no Play Store, no telemetry. The 109 MB download is mostly the bundled video engine and ffmpeg binaries.
